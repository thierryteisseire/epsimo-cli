# Epsimo CLI

The Epsimo CLI lets you manage AI agents, projects, conversations, and deployments from the terminal.

**API Base URL:** `https://api.epsimoagents.com`

---

## Installation

```bash
npm install -g epsimo-cli
```

Requires **Node.js 16+** and **Python 3.8+** at runtime. The npm package includes a Node.js wrapper that bridges to the Python CLI.

After installing, install Python dependencies:

```bash
pip install requests pyyaml click python-dotenv
```

Verify installation:

```bash
epsimo --help
```

---

## Authentication

```bash
# Interactive login (prompts for email/password)
epsimo auth

# Or set environment variables first
export EPSIMO_EMAIL=your@email.com
export EPSIMO_PASSWORD=your-password
epsimo auth
```

Check who you're logged in as:

```bash
epsimo whoami
```

Token is stored locally at `~/.epsimo/token`.

## Commands Reference

### Project Management

```bash
# List all projects
epsimo projects
epsimo projects --json

# Initialize a new project in current directory (creates epsimo.yaml)
epsimo init
epsimo init --name "My Project"

# Deploy configuration from epsimo.yaml
epsimo deploy

# Scaffold a new MVP project from template
epsimo create "My AI App"
```

### Assistants

```bash
# List assistants in a project
epsimo assistants --project-id <PROJECT_ID>
epsimo assistants --project-id <PROJECT_ID> --json
```

### Threads (Conversations)

```bash
# List threads in a project
epsimo threads --project-id <PROJECT_ID>
```

### Interactive Chat

```bash
# Start a live chat session with an assistant
epsimo run --project-id <PROJECT_ID> --assistant-id <ASSISTANT_ID>
```

Streams responses in real-time. Type `exit` or `quit` to end the session.

### Virtual Database

```bash
# Query thread state
epsimo db query --project-id <PROJECT_ID> --thread-id <THREAD_ID>

# Set a value in thread state
epsimo db set --project-id <PROJECT_ID> --thread-id <THREAD_ID> --key <KEY> --value <VALUE>
```

Values are stored as JSON when parseable, otherwise as strings.

### Credits & Billing

```bash
# Check thread balance
epsimo credits balance

# Purchase more threads
epsimo credits buy --quantity 100
epsimo credits buy --quantity 1000 --amount 80.00
```

## Typical Workflow

```bash
# 1. Authenticate
epsimo auth

# 2. Create and initialize a project
epsimo create "My AI App"
cd my-ai-app
epsimo init

# 3. Deploy assistants defined in epsimo.yaml
epsimo deploy

# 4. List what was created
epsimo projects
epsimo assistants --project-id <ID>

# 5. Chat with your assistant
epsimo run --project-id <ID> --assistant-id <ID>
```

## Configuration File (epsimo.yaml)

Created by `epsimo init`. Defines project settings and assistants:

```yaml
project_id: <auto-generated>
name: my-project
assistants:
  - name: default-assistant
    model: gpt-4o
    instructions: "You are a helpful AI assistant."
    tools:
      - type: retrieval
```

`epsimo deploy` syncs this config to the platform — creating new assistants or updating existing ones by name.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `command not found: epsimo` | Run `npm install -g epsimo-cli` and ensure npm global bin is in PATH |
| `python3 not found` | Install Python 3.8+ and ensure it's on PATH |
| `ModuleNotFoundError` | Run `pip install requests pyyaml click python-dotenv` |
| `401 Unauthorized` | Run `epsimo auth` to re-authenticate |
| `Not logged in` | Token expired or missing — run `epsimo auth` |
